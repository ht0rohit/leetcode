# Mistakes Log (future problems only)

This log starts empty. It records mistakes made on problems solved **from now
on**, captured live during the coaching session. It does not and must not
claim to reconstruct mistakes from the 378 problems solved before this system
existed — those are `UNKNOWN` by design (see `submissions/<slug>/metadata.yaml`
and `CLAUDE.md`).

Format per entry:

```markdown
## <date> - <problem title>

- **Mistake**: what went wrong (wrong assumption, off-by-one, wrong data
  structure, missed edge case, etc.)
- **Why it happened**: the reasoning gap that led to it
- **Recognize next time**: the signal that should trigger a different choice
```
